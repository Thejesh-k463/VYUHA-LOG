## 6. Owner's runbook

### 6.1 Mint the review key

`scripts/license-issue.mjs` refuses to mint without a payment reference unless you
pass `--no-payment`, and lifetime is opt-in via `--lifetime`. When
`VYUHA_LICENSE_NOTE` is set it becomes the ledger `note` (`--no-payment` only fills
in a default note when the env var is absent), so set both — the flag says why no
money changed hands, the note says who this is:

```bash
VYUHA_LICENSE_NOTE="creator review copy: [[HANDLE]]" \
  node scripts/license-issue.mjs creator@email.com app --lifetime --no-payment \
  --save-dir "$VYUHA_KEY_ARCHIVE_DIR"
```

- Key goes to stdout; plan, key ID and buyer go to stderr — pipe stdout to a file
  if you want it clean.
- Use the email address the creator gave you: the key is bound to it and shows as
  "Licensed to <email>" in their app.
- Do **not** add `--machine` — a reviewer will run it on more than one PC.
- Send the key plus the installer download / landing file in the same message. No
  receipt is issued (nothing was paid), so do not send `RECEIPT_TEMPLATE.md`.

Full detail on the ledger, archive and encrypted backup: `LICENSE_OPERATIONS.md` §0–§2.

### 6.2 Track who has which key

The ledger is the record. `node scripts/license-list.mjs creator@email.com` (or the
key ID) finds it, and the note field carries the handle. Mirror it here so the
outreach status is visible without the ledger:

Fill a row when you first message a creator, not when they accept — otherwise the
"declined" and "no reply" cases vanish and you re-message the same person in a month.

### 6.3 What NOT to promise

- **Nothing about outcomes.** No returns, no accuracy, no win-rate — for the app or
  for the creator's own trading. If a creator asks "will this make my viewers better
  traders?", the answer is "it will make their records better; the rest is theirs."
- **No revenue share, affiliate code or commission** unless it is agreed later, in
  writing, as a separate arrangement. This offer is a review copy, full stop. Do not
  hint at "maybe later" in the outreach.
- **No exclusivity, no editorial control, no takedown requests** on an unfavourable
  review.
- **No macOS.** Windows only; do not say a Mac build is "coming" on any surface.
- **The public URL is https://thejesh-k463.github.io/VYUHA-LOG/** (GitHub Pages, live
  since 2026-08-15). Link it; attach the standalone HTML only as a fallback — never
  paste a placeholder link that 404s.
- **The trial and free tier are the product's own terms** (7 days; core journal
  free forever) — do not invent extended trials or discount codes for a creator's
  audience without deciding to and recording it in `MONETIZATION_PLAN.md`.

### 6.4 If a creator asks for money

Say no for this round; the offer is a review copy. If paid placements become a
channel later, that is a separate decision with its own ledger line and disclosure
("paid partnership") — record it in `GROWTH_ENGINE_PLAN.md` first.
